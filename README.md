# Guido Javier Masso — sitio personal v0.2

Landing estática diseñada para `https://guidojaviermasso.com/`.

## Incluye
- HTML semántico y responsive.
- Imágenes optimizadas en WebP.
- Canonical definitivo apuntando al dominio elegido.
- `ProfilePage`, `Person` y `WebSite` en JSON-LD.
- Open Graph y Twitter metadata.
- `robots.txt` y `sitemap.xml` listos.
- Enlaces a fuentes públicas externas.

## Publicación recomendada
Para esta versión: GitHub Pages con dominio personalizado, o Cloudflare Pages. No necesita backend ni base de datos.

## Antes de publicar
1. Registrar `guidojaviermasso.com` si está disponible.
2. Confirmar la fecha pública del Frente Cultural: el usuario indica etapa fundacional desde 2017, mientras fuentes académicas publicadas ubican su conformación en 2018. La web usa `2017–2018` como formulación provisoria.
3. Definir un email profesional si se quiere mostrar.
4. Revisar derechos de uso/créditos de las fotografías de actividades.
5. Crear una imagen Open Graph 1200×630 específica en una siguiente versión.
6. Conectar Google Search Console después de publicar.
